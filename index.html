Panduan Setup
Ikuti 4 langkah ini — hanya perlu dilakukan sekali
📋 Langkah 1 — Buka Apps Script
1
Buka Google Sheets Anda

Klik menu Extensions → Apps Script

2
Paste kode Apps Script

Hapus semua kode default, lalu paste isi file aloe_spa_apps_script_v2.gs yang sudah didownload.

3
Ganti Spreadsheet ID

Di baris paling atas kode, ganti YOUR_SPREADSHEET_ID_HERE dengan ID Google Sheets Anda.
ID ada di URL antara /d/ dan /edit:

https://docs.google.com/spreadsheets/d/[ID_INI]/edit
4
Deploy → New deployment

Klik Deploy → New deployment, lalu setting:

Type: Web app
Execute as: Me
Who has access: Anyone ← BUKAN "Anyone with Google Account"

Klik Deploy, izinkan akses, lalu copy URL-nya.

🔗 Langkah 2 — Paste URL di atas
5
Paste URL di kolom header atas, klik "Hubungkan"

Lampu hijau = berhasil terhubung. Jika gagal, cek langkah 4 — pastikan access: Anyone.

6
Test langsung di browser (opsional)

Buka URL ini di tab baru untuk memverifikasi:

← Hubungkan dulu untuk melihat test URL
💡 Jika masih lambat / timeout

• Apps Script gratis ada limit 6 detik per request — jika Database besar bisa lambat
• Pastikan Google Sheets tidak memiliki formula berat yang perlu recalculate
• Coba buka Apps Script → Execution log untuk melihat error detail
• Jika error CORS: hapus deployment lama, buat New deployment baru (bukan edit yang lama)
